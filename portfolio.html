PORTFOLIO

Atividade ja realizada

Criação de uma pagina de agenda online onde cada lider realise o cadastro da sua atividade para validação futura pela comissão de planejamento
Esse sistema facilita a gestão das programações evitando conflito da datas nas programações.
Foi progetado para facilitar o trabalho de todos sem nenhum custo de hospedagem, de manutação. Com um fluxo de acesso baixo, consigo usar ferramentas como firestor para guardar os dados, github como ferramente de hospedar o codigo fonte e vue.js para desenvolver a parte front-end.
Temos implementação de pagina de cadastro de lider pagina de login, pagina de cadastro de evento.
Não precisa de cadastro para visualizar os eventos ja aprovado.

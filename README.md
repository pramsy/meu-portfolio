# Portfólio Pessoal - Ramses Pierre

Este projeto é um portfólio pessoal desenvolvido como atividade do curso de Frontend. O objetivo é apresentar um site simples e responsivo com informações profissionais, projetos e um formulário de contato.

## Sobre o projeto

O site exibe:
- página inicial com apresentação e destaque de projeto
- currículo com perfil, formação, experiência e conhecimentos
- portfólio com descrição do projeto de agenda online
- página de contato com formulário de envio
- página de agradecimento após envio da mensagem

## Tecnologias utilizadas

- HTML5
- CSS3
- Layout responsivo com `flex` e `grid`
- Imagens adaptadas com `<picture>`

## Estrutura de arquivos

- `index.html` — página principal do portfólio
- `curriculo.html` — página de currículo profissional
- `portfolio.html` — página de projetos e descrição de atividade
- `contato.html` — página com formulário de contato
- `mensagem.html` — confirmação de envio de mensagem
- `style.css` — estilos globais e responsivos
- `imagem/` — imagens usadas nas páginas

## Como usar

### Opção 1 - Download direto do GitHub
1. Acesse o repositório no GitHub.
2. Clique em **Code** e depois em **Download ZIP**.
3. Extraia o arquivo ZIP em seu computador.
4. Abra o arquivo `index.html` no navegador.

### Opção 2 - Clonar o repositório
1. Abra o terminal ou prompt de comando.
2. Execute:
   ```bash
   git clone https://github.com/pramsy/meu-portfolio.git
   ```
3. Entre na pasta do projeto:
   ```bash
   cd meu-portfolio
   ```
4. Abra o arquivo `index.html` no navegador.

### Uso
1. Navegue pelas páginas usando o menu superior.
2. No formulário de contato, preencha nome, e-mail e mensagem.
3. Ao enviar, o formulário redireciona para `mensagem.html`.

## Melhorias implementadas

- HTML semântico com `header`, `main`, `section` e `footer`
- títulos únicos e `meta description` para cada página
- navegação consistente e link ativo
- layout responsivo com ajustes para telas menores
- estilo visual mais coeso e moderno
